# Public disclosure boundary

## Purpose

This repository is intended to allow assessors to inspect credible evidence of
independent technical development. It is not a distribution of the Charon
application and does not provide access to investigation material.

## Material suitable for publication

- High-level architecture descriptions.
- Dated, defensible development chronology.
- Sanitised Git commit identifiers and change summaries.
- Reviewed, redacted derivatives of authentic historical and current outputs.
- Explanations of provenance, uncertainty and validation controls.
- Public-safe descriptions of technologies and engineering responsibilities.

## Material that remains private

- Full application source code and database schema details.
- Real cases, clients, subjects, companies and associated identifiers.
- Collected evidence, source documents and database exports.
- Credentials, keys, environment configuration and private infrastructure.
- Detailed collection strategies, assessment thresholds and analytical prompts.
- Commercially sensitive implementation and operational procedures.

## Review gate

Nothing should be published until every file and image has passed a final
confidentiality review. Publication and any GitHub visibility change require a
separate explicit decision after that review.
