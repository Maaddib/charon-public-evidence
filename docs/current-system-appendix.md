# Current-system appendix

This appendix will contain five authentic, redacted views of the present
Charon system:

1. CLI and workflow organisation.
2. Case-management operations.
3. Financial-document extraction and validation.
4. Evidence-supported graph inspection.
5. Structured report generation.

These exhibits demonstrate the endpoint reached by October 2026. They are kept
separate from the historical exhibits so that current capability is not
mistaken for evidence of when each feature was first developed.

The private application-brief screenshots are source material only. Public
derivatives will remove personal and company names, case and evidence IDs,
financial particulars, usernames, hostnames and filesystem paths while
retaining the authentic commands and technical behaviours.
