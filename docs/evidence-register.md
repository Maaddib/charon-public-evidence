# Public evidence register

Historical evidence must be authentic and safely redacted. It must never be
replaced with fictional output. Before an image or excerpt is added, verify
that it contains no personal data, live case identifiers, credentials, tokens,
private repository information, or confidential investigative content.

## Public evidence standard

- Use authentic historical evidence; redact confidential detail rather than
  inventing replacement history.
- Crop terminal chrome to the minimum useful area.
- Use legible text at normal GitHub viewing size.
- Show the command and enough output to substantiate the claim.
- Do not expose implementation source code.
- Add a concise caption explaining what is demonstrated and what is not.
- Retain private originals separately; publish only reviewed derivatives.
- Record the originating repository, commit or file date for every exhibit.
